# analysis/exploratoria

Exploratory analyses of `prereg/plano_exploratorio.md` (E1 to E6) , `prereg/plano_exploratorio_2.md` (E7 to E9) and `prereg/plano_isomax.md` (E10), written after the single confirmatory run. Nothing here is confirmatory, and nothing here changes the frozen scripts in `analysis/`: they are imported read-only, and their SHA-256 is checked against `analysis/README.md` before anything runs.

| File | What it does |
|---|---|
| `exploratorias.py` | E1 (per-event plot), E2 (unflagged errors by class), E4 (ensemble and seed variance per event; ensemble R3 minus ensemble R1 with a 90% interval) and E6 (per-unit Δ_reg against water fraction within events), on the primary target units. Before writing anything it checks that tau of every run, the single-model AUROC_e per event, the unflagged error rate and the pooled ensemble values equal those of the confirmatory run (tolerance 1e-9), and stops if they do not. Refuses an output folder inside the confirmatory one or one that is not empty. |
| `teste_exploratorias.py` | Runs the frozen analysis and then `exploratorias.py` on synthetic data, checks the internal consistency of the tables, and checks that a changed tau or an output folder inside the confirmatory one stops the script. |
| `e3_borda.py` | E3 in two steps. `distancias`: re-reads the original labels with the code of the inference notebook, computes for every scored pixel the Chebyshev distance to the nearest pixel of the other class (per chip for Sen1Floods11, on the whole scene for T2), and stops unless units, sizes and labels equal `labels_<set>.npz` and the pixels with distance 1 or 2 are exactly the `borda` pixels. `analise`: error rate, empty-set rate, unflagged error rate and AUROC_e per distance band, per regime and set; per unit, the Spearman correlation between empty-set rate and water fraction, the partial correlation given the boundary share, and the correlation over the pixels farther than 10 from the boundary. Checks tau and the RQ3 Spearman values against the confirmatory run. |
| `teste_e3.py` | Step 1 on small GeoTIFFs written by the test (including a chip without water and a T2 scene cut into four windows) and a changed boundary flag that must stop it; step 2 on the synthetic margins after the frozen analysis. |
| `e5_r0.py` | E5: from the margins of the released checkpoint (R0) inferred with the week-6 code (`r0_<set>.npz`), tau on the validation set and, on the source test and Bolivia, AUROC_e, unflagged error rate, error rate and mIoU with the frozen `nucleo.py`, next to `analysis/r0_referencia.json` and, for Bolivia, the R3 range of precondition 2. Also `normalizar_chaves`, which maps the checkpoint tensors onto the week-6 model. |
| `teste_e5.py` | Checks `normalizar_chaves` and, on synthetic margins, that tau, AUROC_e, error rate and unflagged error rate equal an independent computation, and that a margin file with other units is refused. |
| `e7_cka.py` | E7: reads the CKA sums written per run by the GPU notebook, computes linear CKA per set, event and block, checks that the R1 run has CKA of at least 0.9999 everywhere, recomputes the AUROC_e of each run on the pooled target with `nucleo.py` (regime means must match the confirmatory run), and writes the tables, the Spearman correlation between CKA at block 23 on the target and AUROC_e over the 10 R2 and R3 runs, and the scatter plot. |
| `e8_misto.py` | E8: draws at most 200 error pixels per run and unit (`numpy.random.default_rng(2)`), with error class, distance band (from the E3 distance files, checked against the labels and boundary flags) and water fraction; fits `BinomialBayesMixedGLM` (variational Bayes) with intercepts per unit, event and run, a GEE with exchangeable correlation, a weighted GEE and the target-only model; writes odds ratios with 95% intervals and the descriptive table. Checks tau against the confirmatory run. |
| `e9_fragmentacao.py` | E9 in two steps. `mascaras`: re-reads the labels and stores, per unit, the grid mask of scored pixels, checked against `labels_<set>.npz`. `analise`: per run and unit, the connected patches of predicted water (8- and 4-connectivity), the fragmentation index (patches per km² of predicted water; no index under 1,000 water pixels), the error rate and the mean MSP; per regime and set, the AUROC of the index and of 1 − mean MSP for bad units, their difference with a 90% bootstrap interval of units within events, the Spearman between the two scores, and the index per event. |
| `teste_e7_e8_e9.py` | Unit tests of the CKA sums, the row sampling and design matrices of E8, the patch count, the index and the weighted AUROC of E9. |
| `teste_e7_e8_e9_ponta.py` | Runs the frozen analysis and then E7, E8 and E9 on synthetic data, end to end. |
| `e10_isomax.py` | E10: compares the R1 runs trained with the IsoMax+ loss (seeds 1 to 3) with the confirmatory R1 runs of the same seeds. Per run and as the mean over seeds, on the validation set, the source test, the pooled primary target and each event: tau, coverage, empty-set rate, error rate, mIoU, unflagged error rate and AUROC_e of the MSP, and for IsoMax+ the AUROC_e of the minimum distance score; contrasts with 90% and 95% intervals from a bootstrap of units within events, the same draws for both arms. Checks tau and the validation AUROC_e of the R1 runs against the confirmatory run. |
| `teste_e10.py` | Runs the frozen analysis and E10 on synthetic data: with IsoMax+ files equal to the R1 margins every contrast must be exactly 0; with other margins the tables must exist and the histogram AUROC_e must match the exact value; a missing file or a non-empty output folder must stop it. |

Run on Colab with `notebooks/semana8_exploratorias.ipynb` (E1, E2, E4, E6), `notebooks/semana8_e3_borda.ipynb` (E3) `notebooks/semana8_e5_r0.ipynb` (E5, needs a GPU), `notebooks/semana11_e7_cka.ipynb` (E7 representations, needs a GPU) `notebooks/semana11_e7_e8_e9_analise.ipynb` (E7 to E9 analysis), `notebooks/semana12_isomax.ipynb` (E10 training and inference, needs a GPU) and `notebooks/semana12_isomax_analise.ipynb` (E10 analysis).
