# notebooks

Colab notebooks for training and inference. Google Drive paths are set in the first cell of each notebook.

| Notebook | What it does | Needs a GPU |
|---|---|---|
| `semana1_higiene.ipynb` | Checks the model hashes against the pinned Hugging Face commit, recomputes the source reference with the conformal threshold calibrated on the validation split and evaluated on the test split, checks 16 vs 32 bit precision, and compares Bolivia against the source test split with chip-level bootstrap confidence intervals for each difference. Reads saved scores only; it does not run the model. | No |
| `semana2_t2_worldfloods.ipynb` | Downloads the WorldFloods v2 test split at a pinned Hugging Face revision, checks every file hash against Hugging Face, copies it to Google Drive, inspects bands, scale, grids and label encoding, and checks the band order from the native resolution of each band, since the files carry no band names (part A). Then computes, per map, the share of labeled pixels inside Sen1Floods11 countries and the cloud fraction, and applies the criteria in `prereg/t2_criterios.md` to write `t2_eventos.csv` (part B). It does not run the model. | No |
| `semana2_t2_janelas.ipynb` | Cuts the T2 maps of the full set into 512 × 512 windows following `prereg/t2_janelas.md`, writes the windows that enter as 6-band images and labels, and writes `t2_janelas.csv`. Checks that every labeled cloud-free pixel is scored exactly once. It does not run the model. | No |
| `semana3_regimes.ipynb` | Installs TerraTorch 1.2.11 with `peft` pinned, records the pretrained backbone `Prithvi_EO_V2_300M_TL.pt` by Hugging Face revision and SHA-256 and copies it to Google Drive, then builds the three fine-tuning regimes (frozen encoder, LoRA, full fine-tuning) with that backbone loaded. Checks the trainable parameter counts against the pre-registration draft, that the encoder tensors equal the pinned file, and a forward pass. It trains nothing and reads no imagery. If Google Drive cannot be mounted it continues on local disk. | Yes, for the forward pass only |
| `semana4_piloto_sementes.ipynb` | Pilot of `prereg/piloto_sementes.md`: trains the frozen-encoder regime with seeds 101 and 102 (pilot-only seeds) at the learning rate chosen by the grid, runs 32-bit inference on the 89 validation chips and saves the logit margins, then compares both runs with the validation scores of the released checkpoint saved on 2026-06-07. Reports error rate, mIoU, error-detection AUROC, the conformal threshold and the unflagged error rate per model, the chip-bootstrap correlation between models, the per-chip correlation and the spread between seeds. Reads only the validation set. | Yes |
